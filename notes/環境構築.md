
- Permission denied (os error 13) とあり、権限不足だと判明。(Linux/Unix系OSで標準的な「権限エラー（EACCES）」のコード)
- 作ろうとした場所が `/usr/local/...` というシステム全体の共有領域（管理者しか触れない場所）になっている
直接環境変数を設定することのできる`sudo`というコマンドを使う。

```
"postCreateCommand": "sudo uv pip install --system numpy matplotlib jupyter ruff mypy"
```

### ClaudeCode利用

Claude Code CLI は Node.js 環境（npm）で動作するツールで、Dev Container 内で利用するには、コンテナ内に Node.js が入っている必要がある。
